## Not incorporated

- **Human Microbiome Compendium (MicroBioMap)** (candidate_low): Amplicon-only, so outside the shotgun scope; its harmonised metadata columns and the study list are a useful comparison for the registry's amplicon_misfiled calls.
- **MGnify (EBI Metagenomics)** (candidate_low): Not ingested: MGnify exposes biome classification, not host phenotype fields; a body-site cross-check remains possible.
- **EMBERS (LLM extraction of metadata from 26,435 gut-microbiome papers)** (candidate_low): Methodologically closest to our approach; ingest only if a table with accessions and verbatim evidence is released.
- **PRIME** (candidate_low): Amplicon-only; useful as a vocabulary reference for phenotype categories.
- **gutMEGA, gutMDisorder, Disbiome, HMDAD, GutMetaNet, HGMT** (not_applicable): No per-sample metadata to ingest; listed for completeness. HGMT (tumour cohorts, 18,630 stool samples) could supply cohort-level condition labels for immunotherapy studies.
