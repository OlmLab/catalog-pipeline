## 1.10.0 — 2026-09-28 (release R2026.9, all-age catalog site)
* **Site rebuilt around the all-age catalog.** Every section — Studies (one page per catalog study), Cohorts, Samples (explorer), Fields, Authors, Scope, Methods, Downloads, Contribute, Changes — is now generated from the `gut_*` catalog tables and the `registry_*` tables; the former infant-only sections are gone. Study pages show the registry classification with its evidence, papers (registry links ∪ curated infant links), authors, age / condition / country / sex mix, per-field coverage by route, the cohort-wide statements applied to the study, evidence examples, a sample table and per-study downloads (`data/studies/<PRJ>.csv.gz|.parquet`, `<PRJ>_determinations.csv.gz`). Cohorts are recomputed at every release: curated cohort records plus registry papers that describe 2–4 catalog studies (or cite 2–4 studies all submitted by the same centre). The contribution worklist covers every catalog study with ≥ 50 samples that is below 50 % coverage on ≥ 3 of the five core fields.
* **Fix — duplicate cohort-wide rows.** 1.9.0 shipped both an R3 (full-text) and an R4 (abstract) row for 58,659 sample × field pairs where a cohort-wide statement existed on both routes; `gut_sample_determinations` now keeps one statement per study × field (route precedence R1 > R2 > R3 > R4, then confidence): 1,787,854 → 1,729,195 rows. `gut_sample_metadata_wide` already carried the winning value and is unchanged.
* README intro rewritten from the `gut_*` / `registry_*` tables (`docs/package_readme_intro.md`); the former infant description is kept under *Infant extension (historical description)*. Release notes gain a catalog and a registry section. No new curation in this release.
