## 1.4.0 — 2026-09-27 — release R2026.2 (community-contribution worklist)
Deterministic changes only; no LLM calls; no value of any 1.3.0 table changed. Adds the read-only worklist that drives the site's `contribute/` pages and the GitHub-Issue contribution intake (MATURITY_PLAN §3.2–3.4; pipeline `config/contribute.yaml`, `docs/CONTRIBUTE.md`).
* **`contribute_worklist.csv`** — one row per OPEN included/uncertain study (at least one of age / delivery / feeding / preterm / antibiotics / probiotic below 0.5 coverage on its catalog_scope samples; body-site scope for studies without catalog_scope samples), ranked by `priority_score = Σ weight × (1 − coverage) × log10(n_catalog_scope + 1)` (weights 3/2/2/1.5/1/0.5). Per study: missing fields, the six coverages, best recoverability tier per field, one `blocker_code` (controlled_access · no_linked_paper · paywalled_abstract_only · tables_unjoinable_need_key · pdf_only_supplement · no_supplement_found · archive_only_uncertain · unitless_age_needs_curator · partial_coverage) with `blocker_detail`, an imperative `unlock_text`, the primary `contribution_type`, linked papers, ENA/NCBI links and a prefilled `issue_url` (Issue form `catalog-contribution.yml`, label `contribution`).
* **`contribute_worklist_fields.csv`** — study × field detail (coverage, n_with_value, best tier, field-level blocker incl. `complete`, evidence ≤ 120 chars).
* Both tables carry `release_added = R2026.2`, `release_retired` (null), `package_added = 1.4.0`; a row is retired when the study becomes complete in a later release.
* Coverage is recomputed from `sample_metadata_wide` on catalog_scope at build time (the shipped `study_field_coverage_matrix.csv` is on a different scope and is unchanged).
* Inputs (registered in the pipeline's `config/inputs.json`, group `contribute`): extraction_worklist_v3.csv, recoverability.parquet, RESCUE_REPORT_v2.md (sample-ID forms), r2_rescue_studies.csv, supp_inventory.parquet, controlled_access_registry.csv. No e-mail address or participant name enters any table.
* `DATA_DICTIONARY.md` section 'Contribute worklist' (every column); README Files-table rows; `build_counts.json` gains `n_worklist_studies`, `n_worklist_fields_rows`.
* Counts unchanged: 389 included studies · 154,206 samples · 72,358 catalog_scope · 618,898 current determinations · Sandpiper 2.0.0.
