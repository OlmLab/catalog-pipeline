## 1.14.0 — 2026-10-01 (release R2026.15, owner review)
* **Interventions** (new; vocabulary `config/vocab/interventions.yaml`, 15 study-level codes: fmt, probiotic, prebiotic_or_fibre, synbiotic, live_biotherapeutic, antibiotic, diet_intervention, dietary_supplement, drug_therapy, surgery, bowel_preparation, exercise, vaccine, phage_therapy, other_intervention).
  * Study level — `gut_studies.interventions` (';'-joined codes; '' = nothing administered) + `intervention_design`, `intervention_detail`, `population_condition`, one verbatim evidence quote, route R4, confidence 0.5–0.55: every catalog study classified from its title, BioProject description and up to 3 linked abstracts by two independent reasoning-model replicates (a code is committed only when both return it; single-replicate codes in `interventions_unreplicated`); deterministic guards exclude observed routine treatment, transplants into animals and in-vitro systems. Only interventions the investigators administered count.
  * Sample level — new field `intervention` (+ `intervention_detail`), route R1, from BioSample attributes that record the subject's arm / FMT recipient status / pre- vs post-intervention timing (adds `placebo` and `no_intervention`). Study-level codes are never copied onto samples: the controls of an FMT trial are not FMT samples.
  * `health_condition = intervention_cohort` cohort statements are recoded to the trial population's underlying condition (e.g. ulcerative_colitis for a UC FMT trial), so "IBD + FMT" is now a health-condition filter plus an intervention filter.
* **Core fields**: age is core at the level of life stage — `age_category` (exact age, else the sample's life-stage attribute, else a paper / abstract cohort statement, else the study's single life stage; basis in `age_category_basis`). `age_at_collection_days` and `sex` move to key fields. Core fields are now age_category, country, health_condition, subject_id; `gut_studies.cov_age_category` added.
* Site: grouped drop-down navigation (Browse · Insights · Registry · Data · About); Atlas under Insights; narrower Studies table (samples, interventions, median Gbp per sample; depth and per-field coverage columns removed — they remain on study pages); the Registry table states for every study whether it is in the catalog and counts samples instead of runs; sample explorer filters for study interventions and sample arms; study pages show an Interventions block; Zenodo concept DOI in the footer and cite box.
