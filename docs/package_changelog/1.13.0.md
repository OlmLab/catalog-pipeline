## 1.13.0 — 2026-09-30 (release R2026.13, cleanup)
* **Repositories renamed** to `OlmLab/microbiome_repo` (site, https://olmlab.github.io/microbiome_repo/), `microbiome_repo-data` and `microbiome_repo-pipeline`; GitHub redirects the old names for git and web (not for the old Pages URL).
* **New per-sample fields (route R1 from BioSample attributes)**: `diet` (+ `diet_detail`), `smoking_status`, `medication` (';'-joined class codes; antibiotics stay in `antibiotic_exposure`), `stool_consistency_bristol`; vocabularies `config/vocab/{diet,smoking,medication}.yaml`.
* **Completion passes**: the original R3 full-text shard 09 (55 studies, blocked by a content filter in R2026.8) re-run; R3b (lifestyle / location / collection_date) completed for the studies the first wave could not process and for the 260 infant-extension studies with open-access full text; R4b completed for 62 studies.
* **Registry gap fill**: ENA studies with blank taxon fields and landmark cohorts absent from the catalog were enumerated, classified and harvested; new human gut shotgun studies enter the registry and catalog (counts in RELEASE_NOTES_R2026.13.md).
* **Data-quality corrections** from the adjudication of items flagged in R2026.11–12 (pouchitis cohort, legacy NEC codes, a mislabelled age category, institute-coordinate locations, new-field conflicts, implausible study-level lifestyle codes) — retired / recoded rows are listed in `dq_corrections` and carry `determined_by = dq_adjudication_v1`.
* **Atlas** rebuilt on the official UNDP HDR 2025 HDI table (HDI 2023) — the transcribed table is gone — with new lifestyle and collection-year observation cards; the observation analyses now ship as `scripts/atlas_observations.py`.
* **Release assets**: the Sandpiper genus/species long tables and `registry_runs` are no longer committed to the data repository; they live on the single-commit `release-assets` branch and are attached to the GitHub Release. The SQLite asset skips the two largest tables.
* Sources page: explicit acknowledgement of the incorporated external resources.
