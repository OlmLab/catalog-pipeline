## 1.11.0 — 2026-09-28 (release R2026.11, external curated resources)
* **Ten external curated metadata resources ingested as route R2 evidence** (owner decision): curatedMetagenomicData curation tables (141,320 rows / 24,547 samples / 118 studies), GMrepo v3 live API (140,605 / 39,805 / 286), Meta2DB (51,784 / 11,338 / 78), HumanMetagenomeDB 1.1 (34,330 / 19,876 / 165), MicrobiomeDB (18,921 / 5,113 / 10), MicrobeAtlas coordinates → country (15,074 / 15,074 / 151, after excluding 17 systematically disagreeing studies), HMP/iHMP via IBDMDB + archived HMASM table (14,152 / 2,456 / 3), mBodyMap (6,404 / 3,070 / 5), African Human Microbiome Portal (6,209 / 2,192 / 15), BugSigDB study-level statements (103 rows / 62 studies). Every row carries `evidence_source = external.<resource>`, an `evidence_locator` URL to the source record, the source's raw value as quote and `determined_by = external_ingest_v1:<resource>@<version>`; confidence 0.6–0.75 so a study's own archive attributes (R1) and supplementary tables (R2 ≥ 0.8) win ties. Health-condition strings were mapped to the vocabulary by written rules and, for the long tail, the utility model (mapping tables in the pipeline repository).
* Effect on `gut_sample_metadata_wide` (579,252 samples): age 23.6 → 26.0 %, sex 28.6 → 31.0 %, BMI 5.3 → 7.0 %, country 90.1 → 91.1 %, health condition 31.0 → 37.5 %, antibiotic exposure 12.5 → 16.5 %; determinations 1,729,195 → 1,861,883 (R2 142,737 → 312,314). Agreement with pre-existing catalog values where both exist: sex 97–100 %, country 91–100 %, age (±10 %) 95–99.9 %, health condition 52–87 % (differences are mostly granularity: study-level IBD code vs per-sample CD/UC).
* Site: the Sources page now acknowledges the incorporated resources (with terms and the ingested counts) and lists the consulted-but-not-incorporated ones; evidence tables link to the source record.
