## 1.12.0 — 2026-09-29 (release R2026.12, owner site review: new fields, collections, atlas)
* **New per-sample fields** in `gut_sample_metadata_wide` / `gut_sample_determinations` (config/packs/gut.yaml): `collection_date` (ISO partial date or interval, as specific as the source gives it), `location_region`, `location_locality`, `location_site` and the composed `detailed_location`, `latitude` / `longitude`, `lifestyle` (+ `lifestyle_detail`; vocabulary config/vocab/lifestyle.yaml). Routes: **R1** deterministic parsers over the BioSample attributes (collection_date, lat_lon and the location keys; distinct location strings normalised by the utility model into region / locality / site with a substring guard — reviewable map `gut_location_map`), **R3b** cohort-level statements from open-access full text (two Sonnet-class replicates, verbatim quotes; 24 shards) and **R4b** statements from abstracts and ENA descriptions (6 shards). Counts are in RELEASE_NOTES_R2026.12.md.
* **Field tiers**: core fields are now age, sex, country, health condition and **subject_id** (antibiotic exposure moved to the key fields next to detailed_location, lifestyle, collection_date, BMI, timepoint); the contribute worklist and the site read the tiers from the pack.
* **`gut_runs.parquet`** (one row per run of a catalog study: accessions, library layout, instrument, read/base counts, first_public, Sandpiper flag, catalog sample_key) and study-level sequencing summaries on `gut_studies` (n_runs_total, Gbp per run mean / median, instrument models, layouts, Sandpiper share).
* **Sandpiper community profiles for the whole catalog**: 372,911 profiled runs → 339,626 samples in 2,084 studies (`gut_sandpiper_sample_summary`, QC flags never dropped) and a genus-level CLR-PCA (`gut_sandpiper_pca_scores` / `_loadings` / `_variance`; 335,956 samples × 383 genera; PC1–5 explain 16.3 / 6.5 / 3.8 / 3.2 / 2.3 %). The genus and species long tables (185 + 199 MB) ship as the release asset `gut_sandpiper_profiles_1.12.0.zip`.
* **Site**: About section (Olm Lab, Anthropic AI for Science), Collections (31 curated sets with pre-entered explorer filters), Atlas (taxon world map over 7,992 taxa × 101 countries, interactive PCA of 335,956 samples, 14 data-driven observations), Downloads & releases merged, Registry page led by the explorer and stating the human/non-human breakdown, simple one-question issue form, study pages with a sequencing block and a plain-language registry classification, sample rows linking to NCBI / ENA / DDBJ, `samples/index.html?sample=` filtering to the sample.
