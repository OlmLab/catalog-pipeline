Releases

Every release of the catalog is frozen and archived as a GitHub Release of the data repository (tag data-v<package>) and a site tag (site-v<package>). Numbered releases (R<YYYY>.<n>) start with {{ first_numbered }}; earlier states are identified by their package version. Every fact row carries release_added / release_retired; the Changes pages list what changed in each release.
