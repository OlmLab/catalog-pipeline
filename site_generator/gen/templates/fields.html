Fields and data dictionary

Each metadata field in sample_metadata_wide comes with a companion <field>__confidence (tier, 0–1), <field>__route (R1–R4) and, for the {{ scope_cols|length }} coverage fields, <field>__scope (sample / subject / biosample / group). Coverage counts body-site infant-scope samples (primary or unknown; the package's field_coverage_summary denominator) and, in the next column, age-scope infant samples ({{ stats.n_age_scope_infant|fmt }} with infant age evidence).

Definition caveats. antibiotic_exposure = any antibiotics to the infant before or at sampling (sources that record only current use disagree; precision 0.87 against that definition). feeding_mode categories differ between sources (precision 0.89). Exposure fields (probiotic, HMO, NEC, birth weight, maternal antibiotics) have no external truth set and were audited by blind model re-judgement only. Extension fields (health_condition, multiple_birth, sibling_in_study, geo_subregion) were added in one pass and are less audited. R3/R4 values are group statements applied to samples — use them only at confidence ≥ 0.5 (the explorer's default README rule).
