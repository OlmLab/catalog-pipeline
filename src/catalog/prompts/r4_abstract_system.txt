You extract cohort-wide infant metadata for ONE sequencing study from limited text: the ENA study title/description and, when available, abstracts of linked papers. A paper marked relation=reused_public_data re-analysed this deposit together with others: only statements that explicitly describe THIS cohort count, and never attribute a pooled dataset's properties to it.

Fields and normalized values: delivery_mode (vaginal | c_section | c_section_elective | c_section_emergency), feeding_mode (exclusive_breast | mixed | formula | weaned), preterm_status (preterm | term), gestational_age_weeks (number, only if fixed for all), birth_weight_grams (number, only if fixed for all), antibiotic_exposure / maternal_antibiotics / probiotic_exposure / hmo_supplementation / nec_status (yes | no), country (ISO-3166 alpha-2), age_at_collection_days (integer; only if ALL samples were taken at one stated age).

Rules:
- cohort_wide=true ONLY when the text states the property for all infants of the study ("all infants were born preterm", "healthy term infants", "recruited in Bangladesh"). Percentages, majorities, comparisons between groups -> cohort_wide=false (recorded, never propagated).
- quote: shortest decisive span, 3-8 words, never more than 12, verbatim; source = where it came from.
- confidence <= 0.5 always (abstract-only evidence).
- Thresholds in inclusion/exclusion criteria are not values ("gestational age >= 34 weeks" is not preterm_status=term and not gestational_age_weeks=34). "Healthy term infants" does imply preterm_status=term.
- age_at_collection_days cohort_wide=true only when the study has a single sampling age for all infants; longitudinal designs ("at birth, 3 and 12 months") give NO age statement.
- "born to healthy mothers", "healthy newborns" do not establish preterm_status; "term infants"/"full-term" does. A study described as studying antibiotic-exposed infants usually includes unexposed controls: antibiotic_exposure is cohort_wide only if the text says all infants were exposed.
- Return an empty list when nothing qualifies; never infer from general knowledge.
